# ติดตั้ง Manga Translator

ใช้เวลาประมาณ 5 นาที ทำครั้งเดียวจบ

**เบราว์เซอร์ที่ใช้ได้:** Chrome · **Microsoft Edge** (ทดสอบแล้ว ใช้ไฟล์ชุดเดียวกัน) · Chromium ตัวอื่นก็น่าจะได้
ถ้า Chrome ของคุณถูกองค์กรจัดการอยู่ Developer mode อาจถูกล็อก → [ขั้นที่ 3ข](#ขั้นที่-3ข--ถ้า-developer-mode-ถูกล็อก) มีทางออก 3 ทาง

**ก่อนเริ่ม เช็คสามข้อนี้:**

| | |
|---|---|
| 💻 | ต้องเป็น**คอมพิวเตอร์** — Chrome บนมือถือลง extension ไม่ได้เลย ไม่ใช่ข้อจำกัดของเรา |
| 🔢 | เบราว์เซอร์ **เวอร์ชัน 113 ขึ้นไป** (เช็คที่ `chrome://settings/help` หรือ `edge://settings/help`)<br>เก่ากว่านั้นก็ยังใช้ได้ แต่ไม่มี WebGPU → ช้าลงประมาณ 5 เท่า |
| 🌐 | ต้อง**ต่อเน็ตตอนใช้งาน** — ขั้นตอนแปลเรียกใช้บริการของ Google (การหาตำแหน่งกล่องข้อความทำในเครื่อง) |

## ขั้นที่ 1 — ขอ Gemini API key (ฟรี ไม่ต้องผูกบัตร)

1. เปิด <https://aistudio.google.com/apikey>
2. ล็อกอินด้วยบัญชี Google
3. กด **Create API key** → เลือกโปรเจกต์ (หรือให้มันสร้างใหม่ให้)
4. กดคัดลอก key เก็บไว้

> key หน้าตาประมาณ `AQ.Ab8...` หรือ `AIza...` แล้วแต่ว่าสมัครตอนไหน — ทั้งสองแบบใช้ได้

**โควตาฟรี:** 1,000 คำขอ/วัน · 15 คำขอ/นาที
เราส่ง **ทั้งหน้าเป็น 1 คำขอ** ดังนั้น 1,000 คำขอ ≈ **อ่านได้ 1,000 หน้า/วัน** ซึ่งเหลือเฟือ

⚠️ ใช้ key ของตัวเองเสมอ อย่าใช้ของคนอื่น และอย่าเอา key ที่ผูกกับโปรเจกต์ที่มีบิลมาใช้

## ขั้นที่ 2 — เตรียมไฟล์ extension

**ถ้าได้รับมาเป็นโฟลเดอร์ชื่อ `chrome-mv3` แล้ว** (ข้างในมี `manifest.json`) → ข้ามไป [ขั้นที่ 3](#ขั้นที่-3--ติดตั้งลงเบราว์เซอร์) ได้เลย
ถ้าไฟล์มาเป็น `.zip` ให้แตกไฟล์ก่อน แล้ววางโฟลเดอร์ไว้ในที่ที่**จะไม่ลบทิ้ง** — เบราว์เซอร์อ่านจากโฟลเดอร์นี้ทุกครั้งที่เปิด ถ้าย้ายหรือลบ extension จะหายไป

**ถ้าได้มาเป็นซอร์สโค้ด** ให้ build เอง — ต้องมี Node.js 20 ขึ้นไปก่อน (โหลดที่ <https://nodejs.org> เลือกตัว LTS · เช็คว่ามีแล้วหรือยังด้วย `node -v`)

```bash
cd extension
npm install      # ครั้งแรกใช้เวลา 1–2 นาที
npm run build
```

จะได้โฟลเดอร์ **`extension/.output/chrome-mv3`** — นี่คือตัวที่จะเอาไปติดตั้ง

> **ขนาดโฟลเดอร์ ~27 MB** เกือบทั้งหมดคือ runtime ของ onnxruntime-web ที่ใช้รันตัวตรวจจับข้อความบน GPU
> **โมเดล** ไม่ได้อยู่ในนี้ — ตอนแปลหน้าแรกจะโหลดเพิ่มอัตโนมัติ **4.7 MB** แล้วเก็บไว้ในเครื่อง ไม่โหลดซ้ำ

> 📦 **จะส่งต่อให้เพื่อน:** zip โฟลเดอร์ `chrome-mv3` **พร้อมไฟล์ `INSTALL.md` กับ `USAGE.md` สองไฟล์นี้**
> ตัวโฟลเดอร์ที่ build ออกมาไม่มีคำอธิบายอยู่ข้างใน ถ้าส่งไปเปล่าๆ เพื่อนจะเปิดมาเจอแต่ไฟล์ `.js`
> และย้ำกับเขาว่า **ต้องขอ API key ของตัวเอง** (ขั้นที่ 1) — key ของคุณมีโควตาแค่ 1,000 ครั้ง/วัน ถ้าใช้ร่วมกันจะแย่งกันหมดตั้งแต่เช้า

## ขั้นที่ 3 — ติดตั้งลงเบราว์เซอร์

1. เปิด `chrome://extensions`
2. เปิดสวิตช์ **Developer mode** ที่มุมขวาบน
3. กด **Load unpacked**
4. เลือกโฟลเดอร์ **`extension/.output/chrome-mv3`** (เลือกตัวโฟลเดอร์ ไม่ใช่ไฟล์ข้างใน)
5. หน้าตั้งค่าจะเปิดขึ้นมาเอง

> ❗ **ถ้าสวิตช์ Developer mode เป็นสีเทา กดไม่ได้ และขึ้นว่า “This setting is managed by your administrator”**
> → ข้ามไปอ่าน [ขั้นที่ 3ข](#ขั้นที่-3ข--ถ้า-developer-mode-ถูกล็อก) ด้านล่าง **เกิดขึ้นจริงบนเครื่องที่พัฒนา extension นี้**

## ขั้นที่ 3ข — ถ้า Developer mode ถูกล็อก

### ก่อนอื่น: เช็คว่าเครื่องคุณโดนอะไรกันแน่

เปิด **`chrome://policy`** (หรือ `edge://policy`) แล้วกด **Reload policies** — หน้านี้แสดง**นโยบายทุกข้อที่มีผลจริง**บนเครื่องคุณ
ดูหัวข้อ **Extension Install Policies** เป็นพิเศษ ถ้าขึ้นว่า **“No policies set”** แปลว่า**ไม่มีกฎเรื่อง extension** บังคับอยู่
อย่าเชื่อตารางด้านล่างว่าตรงกับเครื่องคุณ ให้ดูของจริงจากหน้านั้น

**สิ่งที่เจอบนเครื่องที่พัฒนา** (ตรวจจาก registry จริง):

| ที่ตรวจ | ผล |
|---|---|
| `HKLM\SOFTWARE\Policies\Google\Chrome` | มีคีย์อยู่ แต่ **ไม่มีค่าใดๆ** ข้างใน · มีแค่ subkey `LocalNetworkAccessAllowedForUrls` ซึ่งไม่เกี่ยวกับ extension |
| `ExtensionDeveloperModeSettings` | **ไม่มี** |
| `ExtensionInstallBlocklist` / `ExtensionInstallAllowlist` | **ไม่มี** |
| `HKCU\SOFTWARE\Policies\Google\Chrome` | **ไม่มีคีย์นี้เลย** |
| `HKLM\SOFTWARE\Policies\Microsoft\Edge` | มีคีย์ แต่มีแต่ค่าเกี่ยวกับ Copilot/AI · **ไม่มีข้อจำกัดเรื่อง extension เลย** |

> 🔑 **ประเด็นสำคัญ:** Developer mode ไม่ได้โดนกฎที่เล็งมาที่ extension โดยตรง
> มันเทาเพราะ**เบราว์เซอร์นับว่า “ถูกองค์กรจัดการ” เฉยๆ**
> ดังนั้น **อย่าไปขอผู้ดูแลระบบว่า “ช่วย allowlist extension ตัวนี้ให้หน่อย”** — มันไม่มี blocklist ให้ถอดออกตั้งแต่แรก ขอไปก็ไม่มีอะไรให้เขาแก้

### ทางเลือกที่ 1 — ใช้ Microsoft Edge ✅ *ทดสอบแล้วว่าใช้ได้จริง*

Edge เป็น Chromium เหมือนกัน ใช้ **ไฟล์ extension ชุดเดียวกันเป๊ะ** ไม่ต้อง build ใหม่
และนโยบายฝั่ง Edge บนเครื่องนี้**ไม่มีข้อจำกัดเรื่อง extension เลย** → น่าจะเป็นทางที่เจ็บตัวน้อยที่สุด **ลองอันนี้ก่อน**

1. เปิด `edge://extensions`
2. เปิดสวิตช์ **Developer mode** (มุมซ้ายล่าง)
3. กด **Load unpacked** → เลือก `extension/.output/chrome-mv3`
4. ทำขั้นที่ 4–6 ต่อได้ตามปกติ (เมนูคลิกขวา, ป๊อปอัป, หน้าตั้งค่า เหมือนกันหมด)

**ที่ยืนยันแล้วบน Edge 151 — เครื่องเดียวกับที่ Chrome โดนล็อก:**

- `edge://extensions` แสดง **Manga Translator เป็น “Unpacked extension”** พร้อมปุ่ม Details / Remove / Reload → โหลดเข้าไปได้จริง
- `edge://policy` → หัวข้อ **Extension Install Policies: “No policies set”** → ไม่มีนโยบายเรื่อง extension บังคับอยู่เลย
- ตรวจสอบระบบเขียว ✅ ครบทุกบรรทัด รวมถึง **WebGPU ใช้ได้ (nvidia ampere)**
- คลิกขวาแปลได้ 9 กล่องใน 3 วินาที · แคชทำงาน

> 🟡 Edge **ก็ขึ้นว่า “Managed by your organization · Some settings may be disabled”** เหมือนกัน
> แต่ extension ยังโหลดเข้าไปได้ — **“ถูกจัดการ” ไม่ได้แปลว่า “ห้าม extension”** อย่าเห็นข้อความนี้แล้วถอดใจ
>
> พูดให้ตรง: การทดสอบสั่งโหลดผ่านบรรทัดคำสั่ง ไม่ได้เอาเมาส์กดปุ่มเอง — แต่เป็น**กลไกเดียวกัน**กับปุ่ม Load unpacked
> และบน Chrome ที่ถูกล็อก วิธีเดียวกันนี้**ถูกเมินเงียบๆ** ส่วนบน Edge มันทำงานและ extension ขึ้นในรายการจริง

### ทางเลือกที่ 2 — Chrome for Testing ✅ *ทดสอบแล้วว่าใช้ได้จริง*

เป็น Chrome **คนละตัว**ที่ Google ปล่อยไว้สำหรับการทดสอบ โดยตั้งใจให้**ไม่ผูกกับนโยบายองค์กร**

```bash
npx @puppeteer/browsers install chrome@stable
```

- โหลดลง**โฟลเดอร์ปัจจุบันที่รันคำสั่ง** เป็น `chrome/win64-<version>/chrome-win64/chrome.exe` (~150 MB)
- ไม่ได้แตะ Chrome ตัวเดิม ไม่ได้ทับ profile ไม่ได้ทับ bookmark
- เปิดไฟล์ `chrome.exe` นั้นขึ้นมา แล้วทำขั้นที่ 3 ตามปกติ

⚠️ มันคือ **เบราว์เซอร์แยกอีกตัว ไม่ใช่ตัวแทนของเบราว์เซอร์ที่ใช้ทุกวัน** — ไม่มี profile, ไม่มี password, ไม่มี extension อื่นของคุณ
เหมาะกับ “เปิดไว้อ่านมังงะโดยเฉพาะ” มากกว่าจะย้ายมาใช้ทั้งวัน

### ทางเลือกที่ 3 — เพิ่มค่านโยบายเอง ⚠️ *ทางเลือกสุดท้าย · ยังไม่ได้ทดสอบ*

เพิ่มค่านี้ใน registry **ต้องใช้สิทธิ์ Administrator** แล้ว**ปิด-เปิด Chrome ใหม่ทั้งหมด**:

```
คีย์   HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Google\Chrome
ชื่อ   ExtensionDeveloperModeSettings
ชนิด   REG_DWORD
ค่า    1        (1 = อนุญาตให้ใช้ developer mode)
```

จากนั้นเช็คที่ `chrome://policy` ว่าค่าขึ้นแล้วจริง

> 🛑 **อ่านก่อนทำ:** นี่คือการแก้**นโยบายระดับเครื่อง** ไม่ใช่การตั้งค่าส่วนตัว
> - มีผลกับ**ทุกบัญชีผู้ใช้**บนเครื่องนั้น ไม่ใช่แค่ของคุณ
> - ถ้าเครื่องอยู่ในโดเมนขององค์กร ระบบอาจ**เขียนทับกลับ**ในการ sync รอบถัดไป
> - ถ้าเป็นเครื่องของบริษัท การแก้เองอาจ**ผิดนโยบายความปลอดภัย** — ถามฝ่าย IT ก่อน โดยบอกเขาว่าอยากขอ `ExtensionDeveloperModeSettings = 1` ไม่ใช่ขอ allowlist
>
> **เอกสารนี้จงใจไม่แถมสคริปต์ให้รันอัตโนมัติ** — การแตะนโยบายเครื่องควรเป็นการตัดสินใจของคุณเอง ไม่ใช่ของ installer

## ขั้นที่ 5 — ใส่ API key

1. คลิกไอคอน Manga Translator → กด **ตั้งค่า**
   (หรือคลิกขวาที่ไอคอน → Options)
2. วาง key ลงช่อง **Gemini API key**
3. กด **ทดสอบ** — ต้องขึ้น **ใช้ได้ ✓**
4. เลื่อนลงล่างสุด กด **ตรวจสอบระบบ** — ควรได้ ✅ ครบทุกบรรทัด

ผลที่ควรเห็น:

```
✅ ตัวประมวลผลเบื้องหลัง   เปิดได้ปกติ
✅ WebGPU                 ใช้ได้ nvidia ampere
✅ โมเดลตรวจจับข้อความ     ดาวน์โหลดแล้ว 4.7 MB
✅ Gemini API key         ใช้ได้ · โมเดล gemini-flash-lite-latest
✅ แคช                    0 หน้า · 0 ประโยค · 0.0 MB / 200 MB
```

⚠️ ถ้า **WebGPU** ขึ้นเป็น ⚠️ ก็ยังใช้งานได้ แค่ช้าลงประมาณ 5 เท่า (WASM แทน GPU)

## ขั้นที่ 6 — ลองใช้

1. เปิดหน้ามังงะสักหน้า
   > ⚠️ ถ้าหน้ามังงะเปิดค้างไว้**ตั้งแต่ก่อนติดตั้ง** ต้องกด **F5 รีเฟรชหน้านั้นก่อน**
   > extension เข้าไปทำงานในแท็บได้ตอนแท็บโหลดเท่านั้น — นี่คือสาเหตุอันดับหนึ่งของอาการ “กดแล้วไม่มีอะไรเกิดขึ้น”
2. **คลิกขวาที่รูป → “แปลรูปนี้ (Manga Translator)”**
3. รอประมาณ 3–5 วินาที คำแปลไทยจะขึ้นทับกล่องข้อความ

**ถ้าอยากให้มันแปลเองโดยไม่ต้องสั่ง** — ซึ่งเป็นจุดประสงค์หลักของ extension ตัวนี้ —
คลิกไอคอน → เปิดสวิตช์ **แปลอัตโนมัติขณะอ่าน**
มีผลทันทีกับหน้าที่เปิดอยู่ ไม่ต้องรีเฟรช · จากนั้นเปิดหน้าไหนก็แปลให้เอง เปลี่ยนหน้าก็แปลหน้าใหม่ให้เอง

> 🔋 เปิดอัตโนมัติ = กินโควตาเร็วกว่ามาก (1 หน้า = 1 คำขอ จาก 1,000/วัน)
> ปิดไว้ตอนไล่หาเรื่องที่จะอ่าน แล้วค่อยเปิดตอนเริ่มอ่านจริง

วิธีใช้ทั้งหมดอยู่ใน [USAGE.md](USAGE.md)
