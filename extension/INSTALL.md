# ติดตั้ง Manga Translator

ใช้เวลาประมาณ 5 นาที ทำครั้งเดียวจบ · ต้องใช้ **Chrome** (หรือ Edge/Brave ที่เป็น Chromium) บนคอมพิวเตอร์

---

## ขั้นที่ 1 — ขอ Gemini API key (ฟรี ไม่ต้องผูกบัตร)

1. เปิด <https://aistudio.google.com/apikey>
2. ล็อกอินด้วยบัญชี Google
3. กด **Create API key** → เลือกโปรเจกต์ (หรือให้มันสร้างใหม่ให้)
4. กดคัดลอก key เก็บไว้

> key หน้าตาประมาณ `AQ.Ab8...` หรือ `AIza...` แล้วแต่ว่าสมัครตอนไหน — ทั้งสองแบบใช้ได้

**โควตาฟรี:** 1,000 คำขอ/วัน · 15 คำขอ/นาที
เราส่ง **ทั้งหน้าเป็น 1 คำขอ** ดังนั้น 1,000 คำขอ ≈ **อ่านได้ 1,000 หน้า/วัน** ซึ่งเหลือเฟือ

⚠️ ใช้ key ของตัวเองเสมอ อย่าใช้ของคนอื่น และอย่าเอา key ที่ผูกกับโปรเจกต์ที่มีบิลมาใช้

---

## ขั้นที่ 2 — เตรียมไฟล์ extension

ถ้าได้รับมาเป็นโฟลเดอร์แล้ว ข้ามไปขั้นที่ 3 ได้เลย

ถ้าได้มาเป็นซอร์สโค้ด ให้ build เอง (ต้องมี Node.js 20 ขึ้นไป):

```bash
cd extension
npm install
npm run build
```

จะได้โฟลเดอร์ **`extension/.output/chrome-mv3`** — นี่คือตัวที่จะเอาไปติดตั้ง

> **ขนาดโฟลเดอร์ ~27 MB** เกือบทั้งหมดคือ runtime ของ onnxruntime-web ที่ใช้รันตัวตรวจจับข้อความบน GPU
> **โมเดล** ไม่ได้อยู่ในนี้ — ตอนแปลหน้าแรกจะโหลดเพิ่มอัตโนมัติ **4.7 MB** แล้วเก็บไว้ในเครื่อง ไม่โหลดซ้ำ

---

## ขั้นที่ 3 — ติดตั้งลง Chrome

1. เปิด `chrome://extensions`
2. เปิดสวิตช์ **Developer mode** ที่มุมขวาบน
3. กด **Load unpacked**
4. เลือกโฟลเดอร์ **`extension/.output/chrome-mv3`** (เลือกตัวโฟลเดอร์ ไม่ใช่ไฟล์ข้างใน)
5. หน้าตั้งค่าจะเปิดขึ้นมาเอง

> ❗ **ถ้าสวิตช์ Developer mode กดไม่ได้ และขึ้นว่า “This setting is managed by your administrator”**
> เครื่องนั้นถูกองค์กรตั้งนโยบายห้ามติดตั้ง extension แบบ unpacked ไว้ — ไม่ใช่ความผิดของ extension
> ทางแก้: ใช้เครื่องส่วนตัวที่ไม่ได้อยู่ในนโยบายองค์กร หรือขอให้ผู้ดูแลระบบอนุญาต
> (เจอจริงบนเครื่องที่พัฒนา — ต้องใช้ Chrome for Testing แทนถึงจะทดสอบได้)

---

## ขั้นที่ 4 — ปักหมุดไอคอน

1. กดรูปจิ๊กซอว์ 🧩 ข้างช่องที่อยู่เว็บ
2. กดหมุด 📌 ข้าง **Manga Translator**

---

## ขั้นที่ 5 — ใส่ API key

1. คลิกไอคอน Manga Translator → กด **ตั้งค่า**
   (หรือคลิกขวาที่ไอคอน → Options)
2. วาง key ลงช่อง **Gemini API key**
3. กด **ทดสอบ** — ต้องขึ้น **ใช้ได้ ✓**
4. เลื่อนลงล่างสุด กด **ตรวจสอบระบบ** — ควรได้ ✅ ครบทุกบรรทัด

ผลที่ควรเห็น:

```
✅ ตัวประมวลผลเบื้องหลัง   เปิดได้ปกติ
✅ WebGPU                 ใช้ได้ nvidia ampere
✅ โมเดลตรวจจับข้อความ     ดาวน์โหลดแล้ว 4.7 MB
✅ Gemini API key         ใช้ได้ · โมเดล gemini-flash-lite-latest
✅ แคช                    0 หน้า · 0 ประโยค · 0.0 MB / 200 MB
```

⚠️ ถ้า **WebGPU** ขึ้นเป็น ⚠️ ก็ยังใช้งานได้ แค่ช้าลงประมาณ 5 เท่า (WASM แทน GPU)

---

## ขั้นที่ 6 — ลองใช้

1. เปิดหน้ามังงะสักหน้า
2. **คลิกขวาที่รูป → “แปลรูปนี้ (Manga Translator)”**
3. รอประมาณ 3–5 วินาที คำแปลไทยจะขึ้นทับกล่องข้อความ

ถ้าอยากให้แปลเองอัตโนมัติขณะอ่าน ให้เปิดสวิตช์ **แปลอัตโนมัติเมื่อเลื่อนถึง** ในป๊อปอัป
วิธีใช้ทั้งหมดอยู่ใน [USAGE.md](USAGE.md)

## เรื่องความเป็นส่วนตัวที่ต้องรู้ก่อนใช้

| เรื่อง | ความจริง |
|---|---|
| ภาพถูกส่งออกนอกเครื่องไหม | **ส่ง** — เฉพาะ**ส่วนที่ครอปเป็นกล่องข้อความ** ส่งไปให้ Gemini อ่านและแปล ไม่ได้ส่งทั้งหน้า |
| การหาตำแหน่งกล่องข้อความ | ทำใน**เครื่องคุณเอง**ทั้งหมด ไม่ออกเน็ต |
| API key เก็บที่ไหน | `chrome.storage.local` ของ extension — **ไม่ถือว่าเป็นความลับ** คนที่เข้าถึงเครื่องได้อ่านได้ |
| Google เอาข้อมูลไปเทรนไหม | free tier **อาจนำ prompt/response ไปปรับปรุงโมเดล** ถ้าซีเรียสให้รอโหมด Ollama (M6) |
