# บันทึกการเปลี่ยนแปลง

## 1.0.5 — 2026-10-15

- **การดึงรูปปลอดภัยขึ้น:** แนบ cookie ไปกับรูปเฉพาะเมื่อรูปอยู่เว็บเดียวกับหน้าที่อ่าน · หน้าเว็บสาธารณะสั่งให้ส่วนเสริมดึงรูปจากเครื่องตัวเองหรือเครือข่ายในบ้าน/ที่ทำงานไม่ได้อีก (เว็บอ่านที่ตั้งไว้เองบน LAN ยังใช้ได้) · redirect ไม่พา cookie ตามไป
- รูปหนึ่งหน้าใหญ่เกิน 50 MB ถือว่าผิดปกติและไม่อ่านต่อ
- ทดสอบแล้วกับเว็บที่ต้อง login ที่รองรับ — ใช้ได้เหมือนเดิม

## 1.0.4 — 2026-10-15

- หน้าตั้งค่าไม่เด้งขึ้นเองทุกครั้งที่เปิดเบราว์เซอร์หรือส่วนเสริมอัปเดตอีกแล้ว — เปิดให้เฉพาะตอนติดตั้งครั้งแรก
- เว็บที่เปลี่ยนหน้าโดยไม่รีโหลด (เช่น MangaDex จากหน้ารายการไปหน้าอ่าน) ส่วนเสริมรู้ทันที แปลล่วงหน้าเริ่มได้โดยไม่ต้องรีเฟรช
- เปิดหน้าเดียวกันสองแท็บแล้วแปลพร้อมกันได้ ไม่ขึ้นข้อผิดพลาด
- เปลี่ยนหน้าหรือปิดแท็บระหว่างโหลดรูป งานเดิมหยุดโหลดทันทีและคืนคิวให้หน้าใหม่ · โหลดรูปค้างเกิน 60 วินาทีถือว่าล้มเหลว
- ปล่อยหน่วยความจำของภาพครบเมื่อการตรวจหรือการแปลล้มกลางทาง
- เปลี่ยน OCR runtime ระหว่างกำลังแปลไม่ทำให้งานที่กำลังทำล้ม
- หน้าตั้งค่า: ปุ่ม "ตรวจสอบระบบ" และ "ทดสอบ" ไม่ค้างเมื่อเบื้องหลังยังเริ่มไม่เสร็จ · ไม่ขึ้น "ใช้ครบทุก key แล้ว" ทั้งที่ยังไม่ได้ใส่ key · ตัวเลข MB ใช้หน่วยเดียวกันทุกที่
- เว็บที่ไม่ได้เปิดแปลอัตโนมัติ ส่วนเสริมไม่สแกนรูปบนหน้าเลยแม้แต่ตอนเริ่ม
- เอกสาร: บอกให้ชัดว่าส่งเฉพาะส่วนที่มีตัวหนังสือไป Gemini ไม่ใช่ทั้งหน้า · เขียนเรื่องการดึงรูปจากเว็บที่กำลังอ่านไว้ในนโยบายความเป็นส่วนตัว · ค่าแปลล่วงหน้าและเว็บที่รองรับตรงกับโค้ด

## 1.0.3 — 2026-10-14

ต้องใช้ Chrome / Edge **116 ขึ้นไป**

- กลับมาหน้าที่เคยแปลแล้ว ใช้คำแปลที่เก็บไว้ได้ทันที ไม่ส่งคำขอซ้ำ (เดิมเกิดเมื่อตั้งภาษาต้นทางเป็น "ตรวจเอง")
- คำแปลไม่เลื่อนผิดบอลลูนอีก แม้ Gemini จะตอบกลับมาไม่ครบหรือสลับลำดับ
- คำขอแต่ละครั้งไม่ใหญ่เกินเพดาน เมื่อแปลหน้าปัจจุบันพร้อมหน้าถัดไป
- จำภาษาของแต่ละเรื่องได้แม่นขึ้นเมื่ออ่านหลายหน้าพร้อมกัน และไม่ทำให้แท็บอื่นสะดุดทุกครั้งที่แปลเสร็จ
- ความปลอดภัย: สคริปต์ที่ทำงานในหน้าเว็บไม่ได้รับ API key อีกต่อไป · ตรวจที่มาของคำสั่งภายในส่วนเสริม · ดึงรูปได้เฉพาะ http/https · ตรวจความถูกต้องของไฟล์โมเดลก่อนใช้
- ตัดสิทธิ์ `activeTab` ที่ไม่ได้ใช้
- ไฟล์ดาวน์โหลดมี `SHA256SUMS` ให้ตรวจว่าไฟล์ไม่ถูกแก้

## 1.0.2 — 2026-10-12

- เพิ่มความเข้ากันได้กับเว็บอ่านมังงะที่โหลดภาพผ่าน `blob:` และแปลอัตโนมัติขณะเลื่อนอ่าน
- อ่านภาพที่เว็บโหลดไว้แล้วได้ แม้ URL จะ fetch ซ้ำไม่ได้ โดยใช้ภาพที่แสดงอยู่เป็นทางสำรอง
- แปลภาพหน้าถัดไปที่เว็บ mount ไว้แล้วล่วงหน้าตามระยะที่ตั้งค่า โดยไม่เดา URL และให้หน้าที่กำลังอ่านได้คิวก่อน

## 1.0.1 — 2026-10-09

รุ่นที่จะส่งขึ้น Chrome Web Store · เบต้าบน GitHub Releases

- คำแปลไม่แตกเป็นพยางค์ๆ แล้ว (เดิมบางครั้งขึ้นเป็น "อา รุ ณ ส วั ส ดิ์")
- ข้อความขึ้นบรรทัดใหม่ตรงรอยต่อคำ ไม่ตัดกลางคำ และไม่เล็กจนอ่านยากในบอลลูนแคบ
- กล่องคำแปลปิดตัวอักษรต้นฉบับมิดขึ้น ไม่มีเศษตัวอักษรโผล่ขอบ
- ถ้า Gemini ไม่ตอบภายใน 90 วินาที จะบอกให้ลองใหม่ แทนที่จะขึ้น "กำลังแปล" ค้างไว้
- เมื่อเกิดข้อผิดพลาด รายละเอียดจะอยู่ใน console ของหน้าเว็บตามที่ข้อความแนะนำ

## 1.0.0 — 2026-10-08

รุ่นแรกที่เปิดให้คนทั่วไปติดตั้ง

**ที่ทำได้**
- แปลมังงะญี่ปุ่นและอังกฤษเป็นไทยบนหน้าเว็บโดยตรง วางคำแปลทับบอลลูนเดิม
- แปลอัตโนมัติแยกเป็นรายเว็บ หรือคลิกขวาที่รูปแล้วเลือก "แปลรูปนี้" ได้ทุกเว็บ
- แปลหน้าถัดไปไว้ล่วงหน้าบนเว็บที่เดา URL หน้าถัดไปได้
- ตรวจภาษาต้นทางเองจากตัวอักษรที่อ่านได้จริง
- ชี้เมาส์ที่กล่องคำแปลเพื่อให้จางลงและเห็นภาพข้างหลัง กล่องคำแปลไม่ดูดคลิก
- ใส่ API key ได้หลายอัน ถ้าอันแรกโควตาหมดจะสลับไปใช้อันถัดไปเอง
- ปรับความทึบแยกได้ 2 ชั้น: แผ่นที่ปิดต้นฉบับ กับพื้นหลังของคำแปล
- เปิดหน้าที่เคยแปลแล้วซ้ำจะขึ้นทันทีจากแคช ไม่เสียโควตา

**เปลี่ยนจากรุ่นที่แจกเพื่อน (0.1.0)**
- ข้อความสั้นจะไม่เล็กจนอ่านไม่ออกแล้ว: ตั้งขนาดขั้นต่ำเป็น 13px และให้กล่องขยายออกได้เมื่อข้อความไม่พอดี
- กล่องคำแปลที่ขยายออกจะเลื่อนหลบกล่องข้างๆ ไม่ทับกันแล้ว และข้อความสั้นไม่ใหญ่จนล้นบอลลูน
- โมเดลตรวจจับข้อความมากับตัวส่วนเสริมแล้ว ไม่ต้องดาวน์โหลดตอนใช้ครั้งแรก
- เอาหัวข้อ Ollama ที่ยังใช้ไม่ได้ออกจากหน้าตั้งค่า
