## 2 โหมดการทำงาน

### โหมดสั่งเอง (ค่าเริ่มต้น — แนะนำให้เริ่มจากอันนี้)

**คลิกขวาที่รูป → “แปลรูปนี้ (Manga Translator)”**

- แปลเฉพาะหน้าที่สั่ง ควบคุมโควตาได้เต็มที่
- ใช้ได้เสมอ แม้ปิดแปลอัตโนมัติไว้
- สั่งซ้ำที่รูปเดิม = **แปลใหม่** โดยข้ามแคช (ใช้ตอนผลลัพธ์ไม่ดี)

หรือกดไอคอน → **แปลหน้านี้เดี๋ยวนี้** เพื่อแปลทุกรูปที่เห็นอยู่บนจอ

### โหมดอัตโนมัติ

เปิดสวิตช์ **แปลอัตโนมัติเมื่อเลื่อนถึง** ในป๊อปอัป

- รูปที่กำลังจะเข้าจอ (ล่วงหน้าประมาณ 2 หน้าจอ) จะถูกแปลให้เอง
- เว็บที่โหลดหน้าถัดไปไว้ล่วงหน้า (เช่น MangaDex) จะถูกแปล**ตั้งแต่ยังไม่แสดง** พอกดหน้าถัดไปคำแปลขึ้นทันที
- ทำทีละหน้าเสมอ ไม่ยิงพร้อมกัน

> ⚠️ โหมดอัตโนมัติกินโควตาเร็วกว่ามาก — 1 หน้า = 1 คำขอ จากโควตาฟรี 1,000 คำขอ/วัน

## สิ่งที่เห็นบนจอ

| สิ่งที่เห็น | ความหมาย |
|---|---|
| ป้ายมุมซ้ายบนของรูป | สถานะ: กำลังดึงภาพ → กำลังหากล่องข้อความ → กำลังแปล |
| กล่องขาวทับ bubble | คำแปลภาษาไทย |
| กล่องสีส้มเส้นประ “ถูกปฏิเสธ” | Gemini ไม่ยอมแปลกล่องนี้ (ดูหัวข้อเนื้อหาผู้ใหญ่ด้านล่าง) |
| ป้ายสีแดง | เกิดข้อผิดพลาด — ข้อความบนป้ายบอกวิธีแก้ |

**ชี้เมาส์ค้างที่กล่อง** = เห็นข้อความต้นฉบับภาษาญี่ปุ่น
(ปิด/เปิดได้ที่ ตั้งค่า → การแสดงผล → โหมด)

## ปรับให้อ่านสบายขึ้น

ทั้งหมดอยู่ใน **ตั้งค่า → การแสดงผล**

- **ขนาดตัวอักษร** 0.7–1.5 เท่า — ตัวอักษรไทยยาวกว่าญี่ปุ่นราว 1.5–2 เท่า ถ้าล้นกล่องให้ลดลง
- **ความทึบของกล่อง** — ลดลงถ้าอยากเห็นลายเส้นข้างหลัง

ย่อ/ขยายหน้าต่าง หรือซูมเบราว์เซอร์ ได้เลย — กล่องและขนาดตัวอักษรขยับตามเอง

## เนื้อหาผู้ใหญ่

ตั้งค่า **ปิดตัวกรองเนื้อหาทั้ง 4 หมวด** ไว้ให้แล้วโดยค่าเริ่มต้น

แต่ Google มีตัวป้องกันชั้นในที่**ปิดไม่ได้** ถ้าโดนปฏิเสธ:

1. ระบบจะ**ลองส่งใหม่ทีละกล่องเอง** อัตโนมัติ — กล่องอื่นบนหน้าเดียวกันจะยังได้คำแปลปกติ
2. เฉพาะกล่องที่ยังโดนปฏิเสธจะขึ้นเป็นกรอบส้ม “ถูกปฏิเสธ”
3. ลองสั่งแปลใหม่อีกครั้งบางทีก็ผ่าน

> ถ้าเจอบ่อยจนน่ารำคาญ ทางแก้จริงคือโหมด local (Ollama) ซึ่งวางช่องตั้งค่าไว้แล้วแต่ยังไม่เปิดใช้ (M6)

## เว็บที่รองรับ

| เว็บ | สถานะ | หมายเหตุ |
|---|---|---|
| **imhentai** | ✅ ทดสอบแล้ว | รู้จัก `#gimg` · เปลี่ยนหน้าแล้วคำแปลเก่าหายทันที |
| **MangaDex** | ✅ ทดสอบแล้ว | หน้าโหลดช้ากว่า ต้องรอรูปขึ้นก่อน |

| Shonen Jump+ / Giga Viewer | ❌ ยังไม่รองรับ | วาดใส่ canvas ที่อ่าน pixel ไม่ได้ ต้องใช้ screenshot ซึ่งยังไม่ได้ทำ |

## แคช

- **แคชผลอ่านภาพ** (แพง) เก็บตาม “ลายนิ้วมือของไฟล์รูป” ไม่ใช่ URL → เปิดหน้าเดิมซ้ำจะขึ้นทันที
- **แคชคำแปล** (ถูก) เก็บตามข้อความ → ประโยคซ้ำๆ ทั้งเรื่อง เช่นชื่อตัวละคร จะไม่เสียโควตาอีก
- ที่ **ตั้งค่า → แคช** มี 2 ปุ่ม:
  - **ล้างเฉพาะคำแปล** — อยากแปลใหม่ด้วยโมเดลอื่น แต่ไม่อยากอ่านภาพใหม่ (ประหยัดกว่ามาก)
  - **ล้างทั้งหมด** — เริ่มใหม่หมด
- เพดาน 200 MB ล้นแล้วลบตัวที่ไม่ได้ใช้นานสุดเอง

## แก้ปัญหา

**ก่อนอื่นเสมอ: ตั้งค่า → ตรวจสอบระบบ** ทุกบรรทัดที่ ❌ มีวิธีแก้ต่อท้ายอยู่แล้ว

| อาการ | สาเหตุที่พบบ่อย | ทำยังไง |
|---|---|---|
| คลิกขวาแล้วไม่มีเมนู “แปลรูปนี้” | ต้องคลิกขวาบน**รูป**เท่านั้น | คลิกขวากลางภาพหน้ามังงะ |
| กดแล้วไม่มีอะไรเกิดขึ้น | content script ยังไม่ทำงานเพราะเพิ่งติดตั้ง | **รีเฟรชหน้าเว็บ** แล้วลองใหม่ |
| ขึ้น “ยังไม่ได้ใส่ Gemini API key” | ยังไม่ได้ตั้งค่า | ตั้งค่า → วาง key → ทดสอบ |
| ขึ้น “API key ใช้ไม่ได้” | คัดลอกไม่ครบ / ติดเครื่องหมายคำพูด | คัดลอกใหม่ทั้งบรรทัด ระบบตัดช่องว่างให้เอง |
| ขึ้น “โควตา Gemini เต็ม” | เกิน 15 คำขอ/นาที หรือ 1,000/วัน | รอสักครู่ · ปิดแปลอัตโนมัติ ใช้คลิกขวาแทน |
| ขึ้น “โมเดลไม่มีอยู่แล้ว” | ตั้งชื่อโมเดลเป็นเวอร์ชันที่ Google ปิดไปแล้ว | ตั้งค่า → โมเดล → ใส่ `gemini-flash-lite-latest` |
| ขึ้น “ไม่พบข้อความในภาพนี้” | รูปเล็กไป หรือไม่มีตัวหนังสือจริงๆ | ซูมหน้าเว็บขึ้นแล้วลองใหม่ |
| ขึ้น “ภาพเล็กเกินไป” | ตัวหนังสือสูงไม่ถึง ~14 px | กดเต็มจอ + ซูม 150% แล้วสั่งใหม่ |
| กล่องคำแปลเลื่อนไม่ตรงรูป | เว็บเปลี่ยน layout หลังโหลด | เลื่อนจอนิดหนึ่ง กล่องจะจัดตำแหน่งใหม่เอง |
| คำแปลหน้าเก่าค้างอยู่หน้าใหม่ | **ไม่ควรเกิด** — ผูกกับลายนิ้วมือรูป ไม่ใช่ตัว element | ถ้าเจอ ถือเป็นบั๊ก ช่วยแจ้งด้วย |
| หน้าแรกช้ากว่าหน้าอื่นมาก | ครั้งแรกต้องโหลดโมเดล 4.7 MB + คอมไพล์ shader ~2 วินาที | เปิดสวิตช์ในป๊อปอัปทิ้งไว้ก่อนเริ่มอ่าน ระบบจะอุ่นเครื่องให้ |
| 2 bubble ที่อยู่ติดกันถูกรวมเป็นกล่องเดียว | ค่า dilate สูงไป | ตั้งค่า → ขั้นสูง → ลดค่า dilate |
| ได้กล่องเล็กๆ ทีละตัวอักษร | ค่า dilate ต่ำไป | ตั้งค่า → ขั้นสูง → เพิ่มค่า dilate |

### ดู log แบบละเอียด

ทุกข้อความขึ้นต้นด้วย `[mt:...]` บอกว่ามาจากส่วนไหน

- ปัญหาบนหน้าเว็บ (หา/วาง overlay) → กด F12 บนหน้ามังงะ ดูแท็บ Console (`[mt:content]`)
- ปัญหาการดึงรูป/แปล → `chrome://extensions` → Manga Translator → **service worker** (`[mt:sw]`, `[mt:pipeline]`)
- ปัญหาการตรวจจับ/โมเดล → `chrome://extensions` → **offscreen.html** (`[mt:offscreen]`, `[mt:detector]`)

## ตัวเลขที่วัดได้จริง (RTX 3060 Laptop)

| ขั้นตอน | เวลา |
|---|---|
| อุ่นเครื่องครั้งแรก (คอมไพล์ shader) | ~1.7–2.0 วินาที · จ่ายครั้งเดียวต่อการเปิดเบราว์เซอร์ |

| **รวม cache miss** | **~3–5 วินาที/หน้า** |
| **cache hit** | **ทันที** |
