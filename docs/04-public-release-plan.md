## 2. เลือกช่องทางแจก — ต้องให้ผู้สั่งงานตัดสิน

| | A. GitHub Releases (zip + Load unpacked) | B. Chrome Web Store | C. Edge Add-ons |
|---|---|---|---|
| ค่าใช้จ่าย | ฟรี | 5 USD ครั้งเดียว | ฟรี |
| เวลาก่อนได้ใช้ | ทันที | รอรีวิว (มักเป็นวัน แต่บางทีเป็นสัปดาห์) | รอรีวิว |
| อัปเดตอัตโนมัติ | ❌ ผู้ใช้ต้องโหลด zip ใหม่เอง | ✅ | ✅ |
| ความยากตอนติดตั้ง | ต้องเปิด Developer mode · **บางเครื่องถูก policy ล็อกไว้** (เครื่องนี้เองก็เจอ — D-021) | กดปุ่มเดียว | กดปุ่มเดียว |
| ความเสี่ยง | ต่ำ | ต้องอธิบายเหตุผลของ `<all_urls>` · รีวิวอาจถามถึง site profile ของเว็บผู้ใหญ่ · ถ้าโดนถอด ผู้ใช้หายหมด | คล้าย B |

**ข้อแนะนำ: ทำเป็นสองขั้น**
1. **เบต้าปิดผ่าน A** ให้คนกลุ่มเล็กที่ติดต่อได้ ประมาณ 5–10 คน นานสัก 2 สัปดาห์ เพื่อเก็บปัญหาที่เราไม่เคยเจอบนเครื่องตัวเอง เช่น macOS, การ์ดจอที่ไม่ใช่ NVIDIA, เว็บอื่น
2. **ขึ้น Web Store (B) + Edge (C)** หลังเบต้าเงียบแล้ว เพราะอัปเดตอัตโนมัติคือสิ่งที่ทำให้แจกให้คนแปลกหน้าได้จริง
   - คำอธิบายในร้านพูดถึงแต่การแปลมังงะทั่วไป และใช้ MangaDex เป็นตัวอย่าง
   - **เรื่องที่ผู้สั่งงานต้องตัดสิน:** จะเก็บ site profile ของเว็บผู้ใหญ่ไว้ในเวอร์ชันร้านค้า หรือแยกเป็น build สำหรับ GitHub เท่านั้น

## 3. หลังเปิดใช้

- **โควตา:** ผู้ใช้แต่ละคนใช้ key ฟรีของตัวเอง (1,000 คำขอ/วัน) เราจึงไม่มีค่าใช้จ่ายต่อผู้ใช้ และไม่มีเซิร์ฟเวอร์ให้ล่ม
- **Gemini เปลี่ยนเงื่อนไข:** เราตั้งชื่อโมเดลเป็น `-latest` ไว้แล้ว แต่ถ้า Google ยุบ free tier ผู้ใช้ทุกคนจะใช้ไม่ได้พร้อมกัน — ต้องมีแผนสำรอง (Ollama ซึ่งเก็บ schema ไว้แล้ว)
- **คุณภาพคำแปล:** ตอนนี้ไม่มีอะไรวัดเลย (คิวข้อ 1) — พอมีผู้ใช้หลายคน ทำปุ่ม "คำแปลนี้แปลก" ที่**บันทึกในเครื่อง**แล้วให้ผู้ใช้เลือกส่งเอง (ห้ามส่งอัตโนมัติ เพราะเราไม่มีเซิร์ฟเวอร์และไม่ควรเก็บข้อมูล)
