# ติดตั้ง Manga Translator

แปลมังงะญี่ปุ่น/อังกฤษเป็นไทยอัตโนมัติขณะอ่าน ไม่ต้อง capture ไม่ต้องกดทีละหน้า

ใช้ได้กับ **Chrome · Edge · Brave** (ตัวไหนก็ได้ที่เป็น Chromium)

---

## 1. แตกไฟล์

แตก `manga-translator-extension-x.x.x-chrome.zip` ออกมา

> ⚠️ **วางโฟลเดอร์ไว้ที่ถาวร** เช่น `D:\extensions\manga-translator`
> อย่าทิ้งไว้ใน Downloads แล้วลบทีหลัง — เบราว์เซอร์อ่านจากโฟลเดอร์นี้ตลอดเวลา **ลบเมื่อไหร่ส่วนเสริมพังทันที**

## 2. ติดตั้ง

1. เปิดแท็บใหม่ พิมพ์ `chrome://extensions`
   *(Edge ใช้ `edge://extensions` · Brave ใช้ `brave://extensions`)*
2. เปิดสวิตช์ **โหมดนักพัฒนา / Developer mode**
   - Chrome, Brave → มุมขวาบน
   - Edge → แถบซ้ายมือ ด้านล่าง
3. กด **โหลดส่วนขยายที่แตกไฟล์แล้ว / Load unpacked**
4. เลือก**โฟลเดอร์**ที่แตกไว้ (โฟลเดอร์ที่มีไฟล์ `manifest.json` อยู่ข้างใน)

เสร็จแล้วจะเห็นการ์ด **Manga Translator** โผล่มา

## 3. ขอ API key ของตัวเอง (ฟรี ไม่ต้องผูกบัตร)

> 🔑 **ทุกคนต้องใช้ key ของตัวเอง** — key แชร์กันไม่ได้ เพราะโควตาผูกกับ key
> ฟรี **15 คำขอ/นาที · 1,000 คำขอ/วัน** ซึ่งพอสำหรับอ่านปกติหลายเล่มต่อวัน

1. เข้า https://aistudio.google.com/apikey
2. ล็อกอินด้วยบัญชี Google
3. กด **Create API key** แล้วคัดลอกมา

## 4. ใส่ key

1. คลิกขวาที่ไอคอนส่วนเสริม → **ตัวเลือก / Options**
2. วาง key ลงช่อง **Gemini API key** → กดบันทึก
3. ใส่ได้มากกว่า 1 key ถ้ามี — ตัวที่สองเป็นตัวสำรอง ใช้เมื่อตัวแรกเต็มโควตา

## 5. เปิดใช้กับเว็บที่อ่าน

เข้าเว็บมังงะ → คลิกไอคอนส่วนเสริม → **เปิดสวิตช์**

จำแยกแต่ละเว็บ เปิดไว้ครั้งเดียวครั้งต่อไปแปลให้เอง

## ตั้งค่าที่น่าปรับ

| ตั้งค่า | แนะนำ |
|---|---|
| **ภาษาต้นทาง** | **อัตโนมัติ** — ดูจากตัวอักษรที่อ่านได้จริง ไม่ต้องสลับเอง |
| **แปลล่วงหน้า** | **40 หน้า** — เว็บที่กดเปลี่ยนหน้าจะแปลรอไว้ให้ก่อน |
| **ความทึบ** | ปรับได้ 2 ชั้นแยกกัน — ชั้นปิดต้นฉบับ กับ ชั้นรองข้อความไทย |
| **ชี้เมาส์เพื่อดูต้นฉบับ** | ชี้ที่กรอบแล้วคำแปลจะจางหายชั่วคราว ให้เห็นภาพเดิม |

## ปัญหาที่พบบ่อย

**เปลี่ยนตั้งค่าแล้วหน้าเว็บไม่อัปเดต**
→ กด F5 ที่แท็บนั้น

**อัปเดตส่วนเสริมเป็นเวอร์ชันใหม่**
→ แตกไฟล์ทับโฟลเดอร์เดิม → กด **↻** ที่การ์ดใน `chrome://extensions` → **F5 ทุกแท็บที่เปิดค้าง**
(ถ้าไม่ F5 จะเหมือนส่วนเสริมเสีย ทั้งที่แค่ต้องรีเฟรช)

**แปลช้า / รอนาน**
→ ส่วนใหญ่เป็นที่เซิร์ฟเวอร์ Google ไม่ใช่เครื่องเรา · เวลาตอบแกว่งได้ตั้งแต่ 3 ถึง 50 วินาที
→ ถ้าช้าทั้งวัน ลองเพิ่ม key ที่สอง

**ขึ้นว่าโควตาหมด**
→ ครบ 1,000 คำขอของวันนั้นแล้ว รอถึงเที่ยงคืนเวลา Pacific หรือใส่ key เพิ่ม

**เบราว์เซอร์เตือนเรื่องส่วนเสริมโหมดนักพัฒนาทุกครั้งที่เปิด**
→ ปกติของส่วนเสริมที่ไม่ได้ลงผ่าน Web Store กด **เก็บไว้ / Keep** ได้เลย

**หน้ารายการเลือกเรื่องถูกแปลด้วย**
→ ไม่ควรเกิด ระบบแยกหน้าอ่านกับหน้ารายการอยู่แล้ว ถ้าเจอให้แจ้ง

---

## สิ่งที่ควรรู้

- **รูปทุกภาพถูกส่งไปที่ Google Gemini เพื่ออ่านและแปล** ถ้าอ่านอะไรที่ไม่อยากให้ส่งออก อย่าเปิดส่วนเสริมกับเว็บนั้น
- คำแปลถูกเก็บไว้ในเครื่อง อ่านซ้ำไม่เสียโควตา
- ส่วนเสริมไม่ส่งข้อมูลไปที่อื่นเลยนอกจาก Google และเว็บที่กำลังอ่าน
